# CraftLingo

Shared translation tooling for the Craft apps: reuse meaning, preserve app-specific wording, and make community review a first-class step.

This repository holds trusted validation/export tooling and review policy. Translation candidates belong in the separate [craft-translations](https://github.com/FredApps/craft-translations) repository. A translation service must not receive write access to this repository.

The first implementation is being prepared as a draft pull request. It is not integrated into or released with any application. No translation service is connected and no candidate translation is represented as human-approved.
